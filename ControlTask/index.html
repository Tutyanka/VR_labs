Ding-dong on a custom marker

This page augments the same Ding-dong surface from the previous assignment and anchors it to a unique registration pattern created for this control task.

  1. Print ControlTask/assets/controltask-marker.png.
  2. Glue it to the chosen real object surface.
  3. Open this page on the phone and point the camera at the printed marker.
  4. Record the result for the repository presentation video.
Pattern file: pattern-controltask.patt
Best result: good light, flat printed marker, camera 20-50 cm away, marker fully visible.
